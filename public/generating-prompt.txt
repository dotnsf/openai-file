以下の前提条件を満たすようなチャットボットのフロントエンド（HTML, JavaScript, CSS）を作っていただけますか？

(1) 作るのはチャット画面の HTML １つと、以下のような機能を実装するための JavaScript 、および UI の CSS です。UI は今風の明るい色のインターフェースにしてください。
(2) チャット画面にはチャットのテキストを入力するフィールドと、ファイル添付が可能なボタン、「ファイルクリア」ボタン、「送信」ボタン、そして「新しいチャット」ボタンを配置してください。
(4) ファイル添付のボタンをクリックしてローカルファイルを指定すると、そのファイルを添付します。この状態で「ファイルクリア」ボタンをクリックするとファイル添付が取り消されます
(3) チャットテキストに何かを入力して「送信」ボタンを押すと、チャットテキストを FormData の prompt フィールドの値に入れてください。またファイルが添付されていた場合は file フィールドにファイルを追加してください（ファイルが添付されていなかった時は何も追加しなくてよいです）
(4) 「送信」ボタンを押したら、チャット画面内に自分の入力したテキストとして画面内に反映してください（チャットのテキスト入力フィールドは空にしてください）。同時に上述の FormData を作り、 Multipart/form-data 形式で、http://localhost:3000/api/completion に POST するようにしてください。結果は OpenAI の Responses API と同じ以下のようなフォーマットでかえってきます。CORS についても対応済みの API です。

```
{
  "id": "resp_0d051ee4b61a24fb006a9a74f280f887d0920f34306225ce32",
  "object": "response",
  "created_at": 1788507380,
  "status": "completed",
    :
    :
  "output_text": "確認しました。ざっくりまとめると・・・"
}
```

(5) 上記のレスポンスを得たら "output_text" の値を AI からのレスポンスとして画面内に反映してください。ユーザーの入力テキストと AI からのレスポンステキストは見た目で区別できるようにしてください。
(6) そのまま続けて次のテキストを入力して再度「送信」ボタンが押された場合は同様に再度 AI に（API に）問い合わせを行うのですが、２回目以降は前回実行した時の結果の "id" 値を送信する FormData の "previous_response_id" というフィールドに含めてから送信してください。こうすることでこの問い合わせが前回の問い合わせの続きであることを指定するようにします。
(7) 「新しいチャット」ボタンが押されたら、これまでのチャット履歴画面をクリアして、初めからチャットを行うようにしてください。またこの直後に「送信」する FormData には "previous_response_id" は含めないようにしてください。
(8) このような機能を持った HTML, JavaScript, CSS を作り、１つの zip ファイルにまとめた上でダウンロード可能なリンクを用意してください。
