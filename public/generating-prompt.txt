以下の条件で動くチャットボットのウェブフロントエンド（HTML, CSS, JavaScript）を作ってください：

1. シングルページの HTML, CSS, JavaScript を作ってください。バックエンド部分は不要です。UI は明るいパステルカラーを中心に今風に作ってください。
2. チャットボットとの会話ができるような UI を作ってください。したがって問い合わせ内容を入力するテキストエリアと、クリアボタンと送信ボタンを付けてください。またこれまでのチャット履歴の内容も表示してください。
3. オプションでファイルを添付できるようにしてください。ファイルを添付した場合は添付したファイルに関する質問を問い合わせできるようしてください。
4. 送信ボタンをクリックしたら入力内容を "https://openai-file.xx14ssrk7ur.jp-tok.codeengine.appdomain.cloud/api/completion" へ POST してください。ポスト時のデータフォーマットは OpenAI の Responses API 互換にして送信してください。LLM の種類や API Key はポスト先で指定されるので入力には含める必要はありません。ファイルが添付されている場合は Base64 に変換してポストデータに含めてください。また CORS の対策もできているので気にせずに送信してください。
5. 送信した結果も OpenAI の Responses API の仕様に従ったフォーマットで返されるので、返ってきたデータから返答テキストを取り出してチャット履歴に加えてください。
6. また画面に「新しいチャット」ボタンを付けてください。このボタンをクリックするとチャット履歴がクリアされ、新しい状態でチャットが開始できます。このボタンを押さずに別の問い合わせを行った場合は、直前の返信データの中に含まれたいた id の値を previous_response_id に追加して POST するようにしてください。そうすることで前回の続きのチャットを行うことができるようになります（これも OpenAI Responses API の仕様そのままです）。
7. 送信ボタンを押した後は返答が表示されるか、またはエラーとなるまでの間は別の問い合わせを避ける目的で、画面を暗くするなどして入力を受け付けないようにしてください。
8. HTML, CSS, JavaScript は１つの zip ファイルにまとめてください。その zip ファイルをダウンロードできるようなリンクを付ける形で返答してください。
